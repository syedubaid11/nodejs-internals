You must be hearing V8 a lot while you learn about nodejs , but what exactly is v8?

v8 is google's open source high performance js and web assembly engine , it was initially designed 
to increase the execution of js inside web browsers .

giving chrome a huge boost back in the day .


How it works?

V8 ranslates this code into a more efficient machine code. It compiles JS into machine code at run time by implementing what is called a JIT (Just In Time) compiler.

Major difference being the fact that it does not generate intermediate code.
